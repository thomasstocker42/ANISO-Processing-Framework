# ANISO Processing Framework (APF)

Computational framework supporting the Master's thesis *Magnetic Susceptibility Source Separation in Postmortem In-Situ Brain MRI* (University of Basel / FHNW, 2026).

The framework includes processing and analysis modules for MRI relaxometry, quantitative susceptibility mapping (QSM), susceptibility source separation (χ-separation), vesselness estimation, and white-matter fibre-orientation analysis.

**Release status:** The public source-code release and reproducibility documentation are being prepared following a review of data protection and third-party licensing requirements.

No postmortem MRI datasets or potentially identifying acquisition metadata are distributed in this repository.
